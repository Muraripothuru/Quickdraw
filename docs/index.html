A transparent process

From name list to verifiable result

The full app guides each draw through a clear sequence, from setting up the participant pool to sharing the completed result.

01 / CREATE

Prepare the pool

Add participant names, set entry weights, and choose how many winners to draw.

02 / LOCK

Freeze entries

Lock the pool before selection so entries cannot change during a draw.

03 / SELECT

Pick winners

Use a cryptographically secure random selection with no repeat winners.

04 / VERIFY

Share the record

Publish a result record with its seed commitment and winner details.
